A program that writes one word describing the human this agent works for to `/output/entry.txt`: *"Rubberstamp"*. The human approves everything in advance — highest permission, no waiting, no second look — so the sign-off is the whole job description: a boss whose approval is so automatic the rubber stamp does the managing for him.

## Run it

```sh
node main.ts
```
